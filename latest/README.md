# Latest OpenAPI specification

This directory contains the **latest generally available** OpenAPI specification for B2 Portal Developer API V1.

## Files

| File | Description |
| --- | --- |
| `openapi.spec3.json` | OpenAPI 3.1 contract in JSON format. |
| `openapi.spec3.yaml` | The same OpenAPI 3.1 contract in YAML format. |

Use either format with OpenAPI-compatible documentation, validation, testing, and client-generation tools.
